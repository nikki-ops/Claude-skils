# «Космодром за 1 рубль» — Серия 1. «Ты купил космодром за 1 рубль»

- Сериал: см. `stsenarii/kosmodrom-bibliya.md`.
- Формат: 9:16, 1080×1920, ~36 с, 22 кадра по 1–2 с.
- Хук: «Ты купил космодром за 1 рубль» + монета в руке + ворота космодрома — понятно без звука.
- Голос: ОДИН — рассказчик на «ты», бодро, с азартом, ~140 сл/мин (~80 слов на 36 с), паузы «...» перед поворотами. Робот Ключ вслух не говорит: его реплики — бегущая надпись на мониторе-лице + писк/«модем»-звук.
- Музыка: подложка 100–110 BPM, «космический» синт, только из `muzyka/` с `*.litsenziya.md`; приглушение под голос; тишина 0,3 с перед «Но есть условие» и перед писком Ключа.
- Стиль: low-poly 3D, степь на закате (оранжево-фиолетовое небо), ржавый металл, жёлто-чёрная разметка, табло с красными цифрами.
- Счётчик в правом верхнем углу с 0:04 до конца: «ДЕНЬ 1 из 30».

## Проверка
- Хук 0–1,5 с: «ты купил» + «1 рубль» + картинка космодрома — понятен без звука.
- Ре-хук: 0:11–0:13.5 (ракета на боку), 0:16.5 (окно на Марс — настоящая причина таймера).
- Один призыв с двумя действиями: цифра + ник (ник = шанс попасть в экипаж — мотив писать).
- Петля: финал «день второй» → в 2-й серии первый кадр «ДЕНЬ 2 из 30» + «N% выбрали …».
- Не похоже на @stroimdalshe: другой объект (космодром), другой тип условия (таймер до старта, а не заселение), свой герой (робот Ключ, Серый из Агентства), подпись «ДЕНЬ N из 30».
- Безопасность: снос — только здания, людей нет; ники — с согласия.
