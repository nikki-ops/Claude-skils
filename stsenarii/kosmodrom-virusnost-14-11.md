# Космодром: как сделать серии вируснее — разбор «Деревни за 1 рубль» (14.11.2026)

Образец: TikTok @stroimdalshe «ЧТО ДАЛЬШЕ?» — 174K подписчиков, 1.8M лайков. Компиляция сезона (16 мин): 141K лайков, 20.9K сохранений. Обычная часть 27: 9.8K лайков. Раскадровка: `render/_istochniki/derevnya-za-1-rubl/nablyudeniya.md`. Разбор делали 3 агента: драматургия, экран, упаковка.

## Главное отличие
У них за 90 с: смена кадра каждые 2–3 с, 3 счётчика двигаются в кадре, 2 сюжетные ветки ИЗ КОММЕНТАРИЕВ (карточка с ником и ♥ на экране), провал → учёба → испытание → твист → новая дилемма. У нас сцены по 5–7 с, на табло двигаются только дни, комментариев зрителей в кадре нет, линия ровная.

## Сценарий (серия 3)
1. **Первый кадр — событие + странная цифра**, не процент: «ВЕРЕ 71 · ДВИГАТЕЛЬ 1991» — стенд трясётся, дым. Итог голосования — второй плашкой поверх.
2. **Конфликт до 10-й секунды** (у них провал на 17 с, у нас Серый был на 29 с).
3. **Бренд-строка в первые 7 с**: «Космодром за 1 рубль. Решаете вы.»
4. **Цепочка «проблема рождает проблему»** — 3 звена, на каждое красный штамп (как «проводов нет → столбов нет → медь сдали»).
5. **Провал → учёба → испытание → твист**: Вера: «ключ на 14», Ключ крутит не туда — искры; ночью учатся; утром запуск; твист.
6. **Дилемма в конце с ценой у обоих вариантов** + срок («РЕШЕНИЕ ДО СТАРТА: 27 ДНЕЙ»). Выбор — только последний кадр.
Ограничения сохраняем: без пересказа, без «расследований», голос не ускорять — резать кадры, а не слова.

## Экран (2D-шаблон)
| Что | Где | Трудность |
|---|---|---|
| Смена плана каждые 2.5–3.5 с (камера крупно/общий, вставки) | SC/SCN | большая |
| Субтитры 2–4 слова, цветное только ключевое слово | SUB + ui.js (копия) | малая |
| Живые счётчики: ДНИ / БЮДЖЕТ / ЭКИПАЖ, всплывающая дельта «−3 000 000» | tablo.js | малая |
| Вторая красная наклонная плашка-штамп одновременно с жёлтой | PLQ | малая |
| Карточка реального комментария (ник, текст, ♥) | новый KOM | средняя |
| «ИТОГ ГОЛОСОВАНИЯ» барами в начале | VOTE | малая |
| Инфографика: круг-прицел, стрелки | INFO | средняя |
| Массовка (толпа, «ХА-ХА») | prim.js crowd() | средняя |
| Время суток: утро / закат / ночь | world(tod) | малая |

## Упаковка
- Подпись по формуле: «🚀 Космодром за 1 ₽, день 3. 61% — за Веру. [2 строки событий]. [Вопрос]? 👇»
- Ник зрителя на экране → люди пишут ради попадания в серию. Закреп: «Лучший коммент попадёт в серию 👀».
- **Компиляция** серий 1–7 подряд (5–8 мин) — у них такой ролик дал в 14× больше лайков, чем обычная часть.
- Плейлист «Космодром за 1 ₽ — сезон 1», финал «Подпишись, пока ракета не улетела без тебя 🚀», Telegram в био.
