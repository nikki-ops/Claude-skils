# Модель серии MARS CITY (свод агентов: render/_istochniki/model/04-model.md, 09-model.md)

**Главная формула:** «Мэр решает — жители голосуют — дом за комментарий».

## Хук (0–2 с, читается без звука)
[необычный действующий] + [масштабное действие] + [разрыв «и вот что произошло…»] + [ник в кадре] + выбор А/Б.
Пример: «Кто-то построил стену вокруг чужих домов… и вот что произошло».

## Три слоя в каждом кадре
- A — загадка для всех (новичок понимает за 1,5 с);
- B — узнавание для жителей (ники, кот-мэр, отсылки к прошлым сериям);
- C — одна фраза для новичков: «1 подписчик = 1 дом».

## Структура 25–32 с
0–2 хук-плашка → 2–6 контекст + счётчик → 6–12 развитие → 12–15 ре-хук → 15–20 кульминация (вау) → 20–27 выбор А/Б на экране → 27–32 награда + крючок с датой.
Кривая эмоций: пики 13–18 с и 25–28 с, спад допустим только на 18–21 с.

## Механики (безопасно для детей)
- Коммент: «ник + А или Б» — голос и пропуск в следующую серию; итог голосования — первый кадр следующей серии. Без условия «только за коммент».
- Лайк: честная цель с прогресс-баром (цель ≥ 2,8 % лайков от просмотров, сейчас 1,66 %).
- Репост: «позови друга по нику — поселю рядом», без угроз и личных данных.

## Чего нет в данных
Сеть дала мало: аналогов «город подписчиков» в обзорах не найдено. Модель опирается на наши серии 9–10 и общие правила Shorts (хук 1–3 с, смена кадра 1,5–2 с, ре-хук ~14 с).
