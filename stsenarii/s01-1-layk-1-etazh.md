# s01 «1 лайк = 1 этаж» — короткий ролик 12,5 с (петля)

- Формат: 9:16, 12,5 с = 20 долей при 96 BPM (`muzyka/rost-96bpm.mp3`, своя), без голоса.
- Сцена: `render/seriya/s01-1-layk-1-etazh/scene.html` — на центральной площади карты (162, −84) под бит растёт башня, каждый этаж подписан ником настоящего жителя (случайные 69 из карты). Карта не меняется: башня добавляется в сцену из iframe.
- Ритм: доли 1–4 — по этажу (ники читаются, внизу крупно «@ник»), 5–8 — по 2, 9–13 — по 4, 14–17 — по 8. Доля 18: пустая площадка-верхушка с зелёным пунктиром и плашкой «ТВОЙ ЭТАЖ? лайк + ник в комменты 👇».
- Петля: после верхушки — снова первый этаж на земле, музыка без затухания.
- Почему пересматривают: ищут свой ник на этажах (ставят на паузу), ускорение под бит, короткая длина.
