# Новый город — как собирается карта

Один источник правды: `render/novyy-gorod/zhiteli.json`. Из него строятся **и ролики, и карта-сайт** — житель, дом и участок везде одинаковые.

## 1. Данные жителя
```json
{ "nick": "lazy_bone1", "n": 1, "seria": 1, "stupen": 2, "zakaz": "дом-ракета", "uchastok": [0, 1], "rayon": "Центр", "ulica": "Первая" }
```
- `n` — порядковый номер жителя (кто раньше написал — тот ближе к центру).
- `stupen`: 1 палатка · 2 домик · 3 дом мечты · 4 почётный (улица его имени).
- Вид фасолинки и цвет дома — из ника (`citizenLook`), заказ дома мечты — вручную из комментария.

## 2. Как город растёт (раскладка участков)
- Центр — площадь с табличкой «ГОРОД ПОДПИСЧИКОВ» и домом Прораба.
- Участки выдаются **по спирали кварталами 2×2** вокруг площади: житель №1 — у площади, №200 — на окраине. Кварталы разделены дорогами, раскладка детерминирована номером → дом никогда не «переезжает».
- **Районы открываются по счётчику**: 0–50 Центр · 51–150 Северный · 151–300 Восточный… Тему нового района (озеро, горы, пляж, лес) выбирают зрители в комментах — это отдельная серия «Открываем новый район».
- Дома мечты получают участки покрупнее (2×1) у главных улиц — их видно издалека.
- Улицы называют в честь почётных жителей.

## 3. Как карта используется в роликах
- **Облёт карты** (2–3 с в каждой серии): камера-дрон над городом, счётчик жителей, видно, как вырос город с прошлой серии.
- **«Твой участок №37»**: камера ныряет к конкретному дому — для новых жителей серии.
- **До/после**: тот же ракурс в серии 1 (пустое поле) и сейчас — сильный хук для юбилейных серий.
- Ролик и карта — одна 3D-сцена (как `render/seriya/h01-gorod/scene.html`), только жители и дома грузятся из `zhiteli.json`.

## 4. Карта-сайт для зрителей
- Та же 3D-сцена в браузере: облёт, поиск по нику, клик по дому → карточка жителя (ник, ступень, серия, когда заселился).
- Ссылка в шапке канала и в каждом описании: «Не нашёл себя в ролике? Найди на карте».
- Выкладка на Netlify (ключ у нас есть) после каждой серии.

## 5. Конвейер после каждой серии
1. Собрать комменты с никами (YouTube — агент `mc-zhiteli`; TikTok — скрины).
2. Обновить `zhiteli.json`: новые → палатка; вернувшиеся → домик; топ-заказы по лайкам → дом мечты.
3. Отрендерить облёт и новых жителей для следующей серии.
4. Задеплоить карту-сайт.
