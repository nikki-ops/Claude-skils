# Шортс «Тебя забыли на Марсе» — самостоятельный, ~75 с, ПЕТЛЯ

Концепт: выживание на цифрах (формула аномалий «с 1 по 100 день» / «N правил») → 3 хитрых хода → 2 катастрофы → поворот «100 чёрточек, а ты ставил 99» → **последняя фраза перетекает в первую**:
конец «…и, похоже, это из-за него» → начало «Тебя забыли на Марсе.» = «это из-за него тебя забыли на Марсе».
Без отсылок на длинное видео. Голос — тот же, что в фильме (Eleven v4 turbo, твой). Скорость для шортса **1.05**.

## Текст для озвучки (≈1 150 символов, ≈5,8 тыс. кристаллов)
см. `stsenarii/s01-mars-shorts.ozvuchka.txt` — ВАЖНО: в конце НЕТ точки после «из-за него», голос должен оборваться на подъёме.

## Раскадровка
| Фраза | Кадр |
|---|---|
| Тебя забыли на Марсе. | Крупно: корабль улетает в окне, герой со спины (тот же кадр, что в конце — стык) |
| Корабль улетел, а следующий — через сто дней. | Счётчик «100» падает на экран |
| Воздуха — на тридцать. Еды — на сорок. | Две полоски ресурсов, красные |
| Цифры не сходятся… значит, их надо сломать. | Герой берёт маркер, зачёркивает «≠» |
| Первое: еду делишь пополам… | Пайки режутся, «40 → 80» |
| Второе: картошка… первый росток. | Песок в воде, росток под лампой |
| Третье: воздух… живёшь в темноте. | Генератор O₂, свет гаснет модуль за модулем |
| День 31… буря… Ключ уходит… ползком. | Стена пыли; Ключ в буре у панелей; ползёт на одной руке |
