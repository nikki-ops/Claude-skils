# Разбор стиля ролика «Ghost Army» (образец автора, 59,8 с = 2 файла по ~30 с)

Разобрано по кадрам: сетки каждые 0,5 с, крупные кадры персонажей, поиск склеек (ffmpeg scene). Время — общее от начала ролика.

## 1. Персонажи — точная спецификация

Плоские 2D-фигурки (нарисованы, не 3D), стоят в 3D-мире как плоскости, ловят размытие глубины. Обводка — чёрная, толщина ≈ 3,5 % диаметра головы, концы круглые.

| Часть | Как выглядит |
|---|---|
| **Голова** | Большой круг. Кожа бледно-кремовая `#f3e2c8`, мягкий градиент: светлее сверху-слева, чуть темнее снизу-справа. **Без румянца**, без носа, без ушей. |
| **Каска США** (M1917 «тазик») | Олива `#6b7a2e` с бликом сверху. Купол ≈ 45 % высоты головы, **широкие плоские поля** ≈ 1,25 ширины головы, поля на уровне ~40 % головы — закрывают лоб, глаза сразу под полями. |
| **Каска Германии** | Тёмная серо-зелёная `#4a5040`, глубокая, закрывает до бровей, края расширяются вниз. |
| **Берет** (французский фермер) | Чёрный плоский эллипс с хвостиком, сдвинут набок. Тело синее `#2f6fd0`, усы-«волна». |
| **Кепка** (грабитель) | Чёрная, тело чёрное. |
| **Тело** | «Фасолинка»-капсула. Ширина ≈ 0,9 диаметра головы, высота ≈ 1,9 диаметра. Олива `#6e7d2c` с градиентом (светлее слева, тёмная полоса справа). Голова сидит **поверх** тела, перекрывая его на ~15 %. Пуговицы: 4–5 тёмных точек строго по центру. |
| **Руки** | Тонкие тёмные линии (≈ 2 % головы) из боков тела на ~25 % от верха, висят чуть наружу, на концах — маленькие чёрные кружки-кисти. |
| **Ноги** | Две тонкие тёмно-коричневые палки `#4a3020`, длина ≈ высоте тела, слегка расставлены «домиком». Ступней почти нет. |
| **Рост в мире** | Голова примерно на уровне башни «Шермана» (~2,5 м). |

### Лица (все — несколькими штрихами)
- **Брови есть всегда** — короткие толстые чёрные дуги; ими делается вся эмоция.
- Нейтрально / хитро: глаза — две короткие горизонтальные чёрточки «— —», рот маленький.
- Смех: глаза «^ ^» или «> <», рот — открытая буква D с красным языком.
- Шок: большие белые круглые глаза с обводкой (≈ 18 % головы), маленькие зрачки, брови вверх, рот — красное «о».
- Тревога: брови домиком, рот — мелкая волна, капля пота у каски.
- Анимация: лёгкое покачивание, рот открывается на словах, моргание, наклон головы.

## 2. Мир
- 3D, низкополигональный, **с чернильной обводкой** контуров и внутренних рёбер (как комикс).
- Техника детальная: катки, ленивцы, фары с дужками, антенны, звёзды в круге, номера «USA 30621», «695», швы и ряды заклёпок пунктиром.
- Земля: кислотно-лаймовая `#7ee03a`, **пиксельная текстура** (как в Minecraft) с точками-цветами (белые, жёлтые, розовые, оранжевые), низкие пучки травы. Дорога — пиксельная охра.
- Деревья «на палочке» с кроной из шаров, живые изгороди рядами, европейские дома: бежевые, красные крыши, ставни.
- Небо: голубой градиент, пухлые белые облака. Даль — голубая дымка.
- Тени голубоватые, не чёрные.

## 3. Картинка и свет
- Сильное размытие переднего и дальнего плана (эффект миниатюры), фокус на персонаже/объекте.
- Высокая насыщенность, лёгкое свечение, виньетка.
- **День**: лаймовый + голубое небо. **Ночь**: всё сине-фиолетовое, тёплые окна и фонари. **Закат**: розово-оранжевое небо, всё тонировано в жёлто-оранжевый, тени синие.
- Субтитры: по одному слову, белый жирный (Montserrat/Inter Black), чёрная обводка, по центру ~66 % высоты.

## 5. Звук и текст
- Мужской голос, быстро (~170 слов/мин), без пауз. Музыка тихо, SFX на ключевых словах.
- Структура: хук-парадокс («армия художников обманула Гитлера») → как (3–4 приёма с картинкой) → реакция врага → итог → «и самое странное…» → финальный факт.
