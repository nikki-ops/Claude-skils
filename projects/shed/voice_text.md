# Ресторан из сарая — текст озвучки v2 (Dipper, v4, stab 0.40, sim 0.75, style 0.15, speed 1.10)
Факты: Уба Батлер, The Shed at Dulwich, 2017, TripAdvisor №1 в Лондоне; раньше писал платные фейк-отзывы по £10; «блюда» из пены для бритья, таблеток для посудомойки, губок и собственной ноги; на открытии — готовые обеды из супермаркета.

[dry, punchy storyteller, brisk pace] Парень сделал свой садовый сарай лучшим рестораном Лондона. Не приготовив ни одного блюда. Раньше ему платили по десять фунтов — за фальшивые отзывы чужим кафе. И он подумал: а что, если отзывы будут на ресторан, которого нет? Он фотографирует «блюда». Пена для бритья. Таблетки для посудомойки. Губка для посуды. А одно блюдо — его собственная нога. Адреса нет. «Только по записи». Друзья смеялись: «Шеф-повар губок». Но писали отзывы. Сарай ползёт вверх. Восемнадцать тысячное место. Тысячное. Сотое. Столиков нет — значит, все хотят столик. Телефон разрывается. И однажды утром его сарай — номер один в Лондоне. Выше тысяч настоящих ресторанов. Тогда он всё-таки открылся. На один вечер. Купил в супермаркете готовые обеды по фунту. Разогрел в микроволновке. Подал. Гости спрашивали, можно ли прийти ещё. Это реальная история.
