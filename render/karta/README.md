# Карта города — MARS CITY

Копия сайта https://marsity.netlify.app (Netlify), сохранена 2026-11-10. Один файл `index.html` (Three.js r128 с cdnjs, шрифт Rubik с Google Fonts). Скрипт Netlify HUD при сохранении убран.

## Что внутри (где менять данные)
- `NICK`, `TOTAL` — ник главного жителя выпуска и общее число жителей (`const END=45,NICK='KAPAOKE_KOT',TOTAL=102;`).
- `S` — подписи по словам `[секунда, слово]` для ролика; `<y>`/`<o>`/`<g>` — жёлтый/оранжевый/зелёный.
- `RS` — жители на карте: `[ник на крыше, тип дома, колонка, ряд]`; пустой ник + `'site'` — свободный участок.
- `FREE`, `PLAZA` — свободные места и площадь.
- `LIST` — список ников для поиска «Найди свой дом».
- `SPEC` — особые постройки по просьбам жителей.
- Блоки «пожелания жителей N выпуска» — новые здания по комментариям.
- На странице упомянут файл `nyaaan.mp3`, но на сайте его нет (404).

## Как обновлять
1. Добавить новых жителей в `RS` (свободный `'site'` → ник и тип дома) и в `LIST`; увеличить `TOTAL`.
2. Новые постройки по комментариям — в соответствующий блок пожеланий.
3. Проверить локально в браузере, затем выложить на Netlify (перетащить папку в app.netlify.com → сайт → Deploys или через Netlify CLI с токеном владельца).
