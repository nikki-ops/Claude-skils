# Карта города — MARS CITY

Копия сайта https://marsity.netlify.app (Netlify), сохранена 2026-11-10. Один файл `index.html` (Three.js r128 с cdnjs, шрифт Rubik с Google Fonts). Скрипт Netlify HUD при сохранении убран.

## Что внутри (где менять данные)
- `NICK`, `TOTAL` — ник главного жителя выпуска и общее число жителей (`const END=45,NICK='KAPAOKE_KOT',TOTAL=102;`).
- `S` — подписи по словам `[секунда, слово]` для ролика; `<y>`/`<o>`/`<g>` — жёлтый/оранжевый/зелёный.
- `RS` — жители на карте: `[ник на крыше, тип дома, колонка, ряд]`; пустой ник + `'site'` — свободный участок.
- `FREE`, `PLAZA` — свободные места и площадь.
- `LIST` — список ников для поиска «Найди свой дом».
- `SPEC` — особые постройки по просьбам жителей.
- Блоки «пожелания жителей N выпуска» — новые здания по комментариям.
- На странице упомянут файл `nyaaan.mp3`, но на сайте его нет (404).

## Как обновлять
1. Добавить новых жителей в `RS` (свободный `'site'` → ник и тип дома) и в `LIST`; увеличить `TOTAL`.
2. Новые постройки по комментариям — в соответствующий блок пожеланий.
3. Проверить локально в браузере, затем выложить на Netlify (перетащить папку в app.netlify.com → сайт → Deploys или через Netlify CLI с токеном владельца).

## Районы (перепланировка 2026-11-10)
Блок `// ===== ПЕРЕПЛАНИРОВКА` в `index.html` (стоит перед «ОПТИМИЗАЦИЕЙ») заново раскладывает все дома из `MLIST` по сетке: клетки 52×40 (`X0=-14, Z0=-416`, шаг 60×48), улицы 8 м с разметкой, «зебрами», тротуарами и фонарями; главный проспект z=12 с золотой разделительной. Карта зон — объект `ZN` (`setZ(колонки, ряды, зона)`).
- **Центр** (x 106…218, z −176…8): площадь Основателя с куполом KAPAOKE_KOT, 4 стеклянные башни с горящими окнами, оранжереи, кристаллы; кварталы бизнесов (магазины, кафе, ТЦ «MAGA», студия шаров) и большие общественные здания по краям площади.
- **Сити** (x 226…338, z −128…−88): жители, просившие небоскрёбы/многоэтажки, + декоративные стеклянные башни.
- **Аллея Желаний** (x 106…338, z 16…104): бульвар с кристаллами; крупные и особые постройки по просьбам (замки, корабли, Кремль-шар «страна Марсен», Земля BETA_deta и т.д.).
- **Район TikTok** (север), **Квартал 10 ноября** (середина), **Район YouTube** (запад и юг): кварталы 4×3 (широкие дома) и 5×3 участков; 128 «новостроек» без ника распределены по этим трём районам; пустые участки — марсианские скверы.
- **Промзона** (северо-восток, x 226…338, z −416…−280): ровно 127 строек, забор, арка.
- **Страна Imen** (юго-запад, стена с башнями и флагами, дворец): 12 вступивших в Империю + Imen_Brawl-Stars + o13sova. Рядом через улицу — **Сопротивление** (3 жителя, баррикада, казарма, флаг Проксимы).
- **Зона развлечений** (перенесена целиком), **Космодром**, **Аэропорт «Дон х9щ · Бананчик»** и «ждут рейса» (2 переезжающих на другие планеты) — юго-восток.
- Подписи районов — массив `DL` (переписывается в блоке), вкладки карты — `ZC` в `MAPCFG.tabs`.
- Старые дороги, заборы, вывески и плоскости районов в пределах города убираются; мелкие пристройки у домов (второй дом, питомцы, сады) прикрепляются к дому и переезжают вместе с ним; крупные старые постройки ставятся на свободные клетки.
