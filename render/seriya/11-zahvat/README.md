# Серия 11 «За ночь IMEN захватила участки»
Сцена = живая карта `render/karta/index.html?video` + стены, флаги и кот-мэр на Three.js (`seriya.js`) + 2D-слой (плашки, ники, телефон с картой в Telegram, кнопки, лайк-щит) в `index.html`.
Сценарий — `stsenarii/11-zahvat.md`.

## Что строится на карте
- Стена 1 кольцом вокруг домов yo_meepo, oooominot, Doni03015 (Район YouTube), вторая — вокруг центра (купол KAPAOKE_KOT, cartonsstorm, Max verstappen). Радиусы считаются по координатам домов.
- Флаги на крышах: голубой — город, фиолетовый — IMEN. Ник над крышей остаётся.
- Кот-мэр в костюме с галстуком, защитники со щитами, свиток «ВОЙНА» на воротах Страны Imen.
- Счётчик участков — реальное число домов внутри стен.

## Рендер
1. Node.js 18+, ffmpeg в PATH; один раз в корне: `npm i playwright` и `npx playwright install chromium`.
2. Озвучка — `golos/11-zahvat.mp3` (подмешивается сама, −14 LUFS; эффекты из `../10-777-domov/sfx`).
3. `node render/seriya/11-zahvat/render.mjs --fps 60` → `gotovo/11-zahvat.mp4` (1080×1920).
   - Черновик: `--fps 10 --scale 0.5 --out gotovo/11-zahvat-chernovik.mp4`, кусок: `--from 12 --to 16`.

## Привязка к голосу
Всё в `seriya.js` задано во времени сцены (0–30 с по таймлайну). Таблица `AN` = `[время голоса, время сцены]` по паузам озвучки — меняется только она; субтитры, камера и эффекты сдвигаются сами.
