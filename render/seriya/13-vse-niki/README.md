# 13 · «Все ники» — сцена шортса

Сценарий и озвучка: `stsenarii/13-vse-niki.md`. Карта `render/karta/index.html` открывается внутри iframe и **не меняется**: камера, подписи, счётчик, телефон и субтитры — поверх неё.

## Посмотреть в браузере
Из корня репозитория запустить любой локальный сервер (например `npx serve .` или `python -m http.server`) и открыть
`/render/seriya/13-vse-niki/scene.html` → дождаться «Нажми R» → **R** — режим записи (курсор скрыт, всё лишнее убрано, ролик играет в реальном времени — можно снимать экран).

## Рендер в mp4 (1080×1920, 30 к/с, без звука)
```
node render/seriya/13-vse-niki/video.mjs                       # демо → gotovo/13-vse-niki-demo.mp4
node render/seriya/13-vse-niki/video.mjs --fly 37 --out gotovo/13-vse-niki.mp4   # полный: все 1 434 ника
node render/seriya/13-vse-niki/video.mjs --kadry 0.3,2.7,10     # проверочные кадры → render/_istochniki/13/
```
Нужны Node 18+, `playwright` (chromium) и ffmpeg. Рядом с видео пишется `*-taymkody.txt` — «секунда — @ник» для каждого показанного жителя.

## Конфиг (`CFG` в начале скрипта scene.html)
- `FLY_SEC` — длина пролёта: **6 = демо**, для финала — 37 (ровно все ники, 61 кадр) или 50 (`// КОНФИГ: поменять 6 сек на 50 сек`).
- `FRAME` 0.6 — кадр; `PHONE_SEC` 8 — финал; `LOOP_SEC` 0.6 — возврат к первому кадру (петля).
- `SECRET_FRAME` 5 — кадр пасхалки; `SEED` — какой ник печатается в телефоне; `SUB_Y` — высота субтитров; `VIEW` — камера.

Кадры подбираются автоматически (жадное покрытие): каждый из 1 434 жителей подписан хотя бы в одном кадре; жители в основании Золотой башни подписаны столбиком на башне. Первый кадр — обычный жилой квартал (хук).
