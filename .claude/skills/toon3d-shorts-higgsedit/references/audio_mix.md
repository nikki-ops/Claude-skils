# Звук: темп, музыка, SFX, сведение

Детали референса — в `analysis/Ref_audiopacing_analysis.md`. Голос сухой, близкий, очень быстрый (около 230 слов/мин), почти без пауз. Под ним всё время тихая музыкальная подложка (регтайм или свинг на −21…−24 dB к голосу) и предметные звуки.

## Голос (`scripts/voice_compact.py`)
1. Склеить выбранные дубли по порядку (48 кГц, моно).
2. `silencedetect=n=-38dB:d=0.12` → каждую паузу длиннее 0.2 с ужать до 0.2 с (половина паузы с каждой стороны).
3. `atempo` подобрать под целевую длину: 205 слов/мин в «Фонаре» (1.27), около 210 слов/мин в «Не врать» (1.19). Добавить `highpass=70` и мягкий компрессор `threshold=-18dB:ratio=2.5`. Жёстче не сжимать: интонация становится плоской.
4. Снова распознать финальный `voice.wav` через faster-whisper (`word_timestamps=True`) → `words.json`. На нём строятся субтитры и тайминги планов.

## Музыка и SFX (`templates/boat-lantern/audio/synth.py`)
Всё синтезируется на numpy, без внешних библиотек звуков.
- **Музыка:** 151 BPM, ре минор. Щипковые (Karplus-Strong), маримба, колокол, лёгкий бас. Под голосом на −21 dB, с сайдчейном по голосу.
- **SFX под события:**
  - звон и треск копилки, монеты;
  - свист на whip-переходах;
  - море, ветер;
  - смех толпы;
  - шипение и щелчки рации;
  - колокол на старте и финише;
  - шелест купюр;
  - глухой удар на крючке.
- Без эмбиента ролик воспринимается как брак (`feedback_montage`).

## Сведение (`scripts/mix.sh`)
```bash
ffmpeg -y -i voice.wav -i music.wav -i sfx.wav -filter_complex \
"[0:a]aresample=48000,apad=whole_dur=$T,asplit[va][vb];[1:a]volume=-21dB[m];[2:a]volume=-9dB[s];\
[m][va]sidechaincompress=threshold=0.05:ratio=3:attack=20:release=300[md];\
[md][vb][s]amix=inputs=3:normalize=0,loudnorm=I=-14:TP=-1.5:LRA=9,atrim=0:$T[o]" \
-map "[o]" -ar 48000 -ac 2 mix.wav
```
Проверить итог: `ebur128=peak=true`, около −14 LUFS (допуск ±1), пики ≤ −1 dBTP. Если громкость ниже −15, поднять простым `volume`. Если пики близко к 0 — добавить `alimiter=limit=0.89`.
