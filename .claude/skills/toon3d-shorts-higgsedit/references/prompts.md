## 2. Сценарий
### 2.1 Промт на сценарий (если юзер не дал текст)
```
Напиши сценарий вертикального ролика на <длительность, 30–60> с, по-русски, про <тема/сеттинг>.
Темп рассказчика ~205 слов/мин → примерно <длительность × 3.4> слова. Пауз нет, фразы короткие.
Структура строго такая:
1. Крючок-парадокс: «Он поставил всё на самое <медленное/безнадёжное> …».
2. Насмешки окружающих (кто смеётся и почему).
3. «Потому что у него был <X>» — секретный инструмент.
4. Объяснение трюка: почему X даёт преимущество (задержка информации, сигнал издалека и т. п.).
5. Неудачные попытки: «раз за разом … ничего».
6. Финальная попытка и сигнал (вспышка, звук, знак).
7. Ставка: герой молча ставит всё.
8. Развязка: смеявшиеся замолкают.
Правила: числа словами; без имён реальных людей; не копировать сюжет «How a Mirror Rigged a Horse Race»
(зеркало, скачки, ферма) — только формулу. Каждое предложение = один план (1,5–4 с), дай рядом с ним
одной строкой, что в кадре. Без вступлений и морали.
```
### 2.2 Пример: «Фонарь с катера»
Восстановленный текст — `templates/boat-lantern/script.txt` (139 слов, 41,8 с). Оригинальный дубль в архив не попал. Текст собран по 17 планам из `shotsA.jsx`/`shotsB.jsx`, поэтому перед переозвучкой его стоит сверить с роликом.

## 3. Голос
### 3.1 ElevenLabs v4 (Content Factory)
```
generate_audio {params:{
  model: "elevenlabs_v4", stability: 0.40, batch_size: 1,
  prompt: "[dry, punchy storyteller, brisk pace]",
  dialogue: [{ text: "[dry, punchy storyteller, brisk pace] <весь текст одним дублем>",
               voice_id: "7c2133e5-68ab-511f-9aed-9a67664382b1", voice_type: "preset" }]
}}
```
- Новые теги в квадратных скобках ставить только там, где меняется подача: `[smug]` на ухмылке, `[sudden]` на вспышке, `[quiet, satisfied]` на развязке.
- КАПСОМ — не больше одного слова на предложение. Не просить «slow».

### 3.2 fish.audio, голос «Меллстрой»
Без текстового промта: S2.1 Pro, скорость 1.2x, нормализация включена. Текст делится на куски весом ≤ 490 (кириллица ×2). Код — в `voice_fish_audio.md`.

## 4. Разбор референса: задания агентам
Запускать параллельно, по одному агенту на задание. Формат отчётов — как в `references/analysis/`.

### 4.1 Отрезок видео (×6, по ~11 с)
```
Ты разбираешь отрезок <A>–<B> с видео <path/ref.mp4> (30 fps). Кадр n = round(t*30).
Выгрузи все кадры отрезка (ffmpeg -ss <A> -to <B> -vf fps=30) и пройди их покадрово.
Отчёт сохрани в refs/Ref_analysis_<A>-<B>s.md, по-английски, по разделам:
0. Global findings — склейки (scene score), ритм камеры (mean |Δ| кадр-к-кадру), пост-обработка.
1. Shot / move table — | # | frames | time | what | transition in/out |.
2. Shots in detail — для каждого плана: камера (направление, скорость, easing, пик), декорация
   (что построить в 3D, размеры в метрах), свет, персонажи (поза, лицо, моргания с номерами кадров,
   костюм, hex), реквизит, эффекты (частицы: количество, скорость px/кадр, гравитация).
3. Colour palette — hex как среднее по пятну 5×5, с подписью, откуда взят.
4. Characters — конструкция (голова, обводка: толщина слева-сверху и справа-снизу), пропорции в %.
5. Effects summary.
6. Captions — шрифт, кегль в px, y, обводка, тайминг появления относительно слова.
Только измеренные цифры. Где не уверен — пиши «≈» и как мерил. Ничего не придумывай.
```
### 4.2 3D-вид и свет (×1)
```
Сними 22 кадра <ref.mp4> через каждые 3 с и 2–3× кропы деталей. Опиши так, чтобы это можно
было повторить на GLSL raymarching: модель затенения (терминатор, ступени, спекуляр, AO с цветом),
обводка 3D (цвет, ширина ближе/дальше), текстуры с hex (дерево, пол, обои, трава, облака),
ключевой/заполняющий/отражённый свет (направление вектором, цвет), камера (объектив в мм,
высота), DOF, дымка, грейд (насыщенность, контраст, подъём чёрного), как 2D-персонажи сидят в 3D.
В конце — GLSL-рецепт для каждой локации. Файл: refs/Ref_3D_render-look_analysis.md.
```
### 4.3 Звук и темп (×1)
```
Разбери звук <ref.mp4>: faster-whisper small/int8 с word_timestamps → words.json.
Посчитай: слова/с по фразам, паузы между словами и предложениями (гистограмма), F0 (pyin),
сухость/реверб, компрессию (crest, LRA), итоговые LUFS/TP. Музыку слушай по side-каналу (L−R):
уровень относительно голоса, BPM (автокорреляция онсетов), тональность (chroma), инструменты,
где музыка меняется по сюжету. SFX — список с таймингами. Файл: refs/Ref_audiopacing_analysis.md.
```
### 4.4 Сводка стиля
```
Собери refs/style.md по образцу references/STYLE_RULES.md из всех отчётов refs/Ref_*.md.
Где отчёты расходятся — бери покадровый замер, а не оценку на глаз, и отметь расхождение.
```

## 5. Самопроверка (промт самому себе перед сдачей)
```
Перед сдачей пройди references/self_check.md целиком. Для каждого плана:
1) hstack свой кадр и кадр референса в одном масштабе (540×960) и сравни: кадрирование, % головы
   от ширины кадра, горизонт, субтитры, цвет;
2) кропы: лицо героя, шляпа, бабочка, реквизит, пол, ткань, облака, фон;
3) стыки склеек по кадрам: чёрные кромки, двойные субтитры;
4) глубина: фон размыт и в дымке, передний план размыт, герой резкий;
5) ffprobe 1080×1920, длительность, аудио; ebur128 ≈ −14 LUFS, TP ≤ −1;
6) распознай финальный голос и сверь со сценарием.
Если хоть что-то проще референса — исправь и проверь снова. Юзеру не показывай промежуточное.
В ответе: что проверено покадрово, что не смотрел подряд, чем отличается от референса, какой голос.
```

## 6. Жёсткие запреты (из замечаний юзера)
Цитаты юзера и то, что из них следует:
- «плоско, нет 3D» / «нет эффекта 3D, причём не эффекта, а именно 3D» → только GLSL-декорации.
- «Почему я должен тебя просить? Ты же можешь делать самопроверки» → самопроверка до сдачи.
- «нарисовано ребёнком» → детализировать шляпы, бабочки, реквизит.
- «Это и придаёт объём» → дымка и размытие на переднем плане.
- «серо и блекло» → насыщенность и контраст, тёплый свет, фиолетовые тени.
- Дёрганье «на двойках» на крупных планах → только плавное дыхание.
- Голова — замеренная «булка» `HR`, не круг. Других форм не предлагать.
