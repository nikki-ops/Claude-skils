# Исходник ролика «Фонарь с катера» (Higgsedit, 1 ноября 2026)

Код восстановлен из истории сессии: все команды песочницы проиграны заново. 2 ноября 2026 он проверен: `higgsedit build film.jsx` проходит, кадры 4.5 с (терраса со смеющейся толпой) и 29.5 с (шторм, яхты, №7) рендерятся как в финальном ролике.

## edit3d/ — финальная версия (3D-декорации + 2D-персонажи)
| Файл | Что внутри |
|---|---|
| `lib.glsl` | База Content Factory + `hexc`, `softSh`, `shadeR`, `post` |
| `terrace.glsl` | Терраса ресторана (настил, перила, зонт, столик, море, небо) |
| `booth.glsl` | Будка букмекера (параметры `u_lamp`, `u_radio`, `u_shake`) |
| `sea.glsl` | Регата: яхты `a1/a2/a3/a7`, `u_cap` (переворот), `u_storm`, `u_dusk`, `u_fin` |
| `cliff.glsl` | Мыс с прожектором (`u_beam`, `u_aim`) |
| `rig.jsx` | `GL` (шейдеры), `DEF` (камеры по умолчанию), `Set3D` (двухслойная глубина резкости), `Sc` (вход cut/fade/whip, 2D-камера) |
| `char.jsx` | `Toon` — персонажи (замеренная голова, кистевая обводка, лица, костюмы `OUTFIT`, позы рук, смех, шляпы) |
| `props.jsx` | `Yacht`, `Radio`, `Waves`, `Searchlight`, `Flash`, `Bill`, `CashStack`, `Lemonade`, `Piggy`, `Burst`, `MoneyRain`, `Hammer`, `Binoculars`, `OddsBoard` |
| `shotsA.jsx`, `shotsB.jsx` | 17 планов S1–S17 |
| `film.jsx` | Сборка: `CUTS` (тайминги планов), субтитры из `captions.json`, звук `../mix.wav` |
| `b.jsx`, `c.jsx`, `s.jsx`, `t.jsx`, `probe.jsx`, `bg.jsx` | Тестовые сцены для отдельных декораций и проб |

Для сборки нужны `captions.json` (из `scripts/captions.py`) и `../mix.wav` (из `scripts/mix.sh`).

## edit2d_v1/ — первая, плоская версия
Её юзер забраковал: «плоско, нет 3D». Оставлена только для сравнения, на её основе не строить.

## audio/synth.py
Синтез музыки и SFX на numpy. Тайминги событий заданы под «Фонарь» — менять их под новый сценарий.
