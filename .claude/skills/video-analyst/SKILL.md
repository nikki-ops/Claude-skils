# video-analyst — разбор вирусных роликов и сценарий мультика

## Пути проекта

- `stsenarii/` — сюда сохраняются разбор и готовый сценарий.
- `golos/`, `muzyka/`, `render/`, `gotovo/` — используются дальше навыками озвучки и рендера (Remotion / HyperFrames).
- `render/_istochniki/` — временная папка для скачанных роликов и кадров. Она в `.gitignore`, чужие ролики в репозиторий не коммитить.

## Шаг 0. Получить материал

1. Ролик может прийти ссылкой (YouTube, YouTube Shorts, TikTok) или файлом.
2. Ссылку скачать в `render/_istochniki/<slug>/`: `yt-dlp -f "bv*[height<=720]+ba/b" -o "render/_istochniki/<slug>/video.%(ext)s" <URL>`. Если `yt-dlp` нет — `pip install yt-dlp`. Если скачать нельзя, попросить файл или разбирать по тому, что доступно (описание, субтитры), и прямо написать, чего не хватило.
3. Технические данные: `ffprobe -v error -show_entries format=duration:stream=width,height,r_frame_rate -of json video.*`.
4. Кадры для просмотра:
   - хук: `ffmpeg -i video.* -t 3 -vf fps=4 hook_%02d.jpg`;
   - склейки: `ffmpeg -i video.* -vf "select='gt(scene,0.3)',showinfo" -vsync vfr cut_%03d.jpg 2>&1 | grep pts_time` — времена склеек;
   - обзор: 1 кадр в секунду (`fps=1`) для коротких роликов, реже для длинных.
5. Речь: субтитры (`yt-dlp --write-auto-subs --skip-download`) или транскрипция (навык `media-use` / whisper). Фиксировать тайминги фраз.
6. Звук: громкость и паузы — `ffmpeg -i video.* -af silencedetect=noise=-30dB:d=0.3 -f null -`.

Кадры смотреть через Read (изображения), а не угадывать содержимое.

## Шаг 1. Хук (0–3 секунды)

- Что именно происходит в первых 3 секундах: первая фраза, первый кадр, текст на экране, звук.
- Тип хука: вопрос, шок/неожиданность, обещание результата, конфликт, «посмотри, что будет», движение/звук, узнаваемый персонаж.
- Почему зритель не пролистнёт: какое любопытство или эмоция создаётся.
- Через сколько секунд появляется первая смена кадра.

## Шаг 2. Структура

Разметить по таймкодам:

| Блок | Время | Что происходит |
|---|---|---|
| Завязка | | герой, ситуация, проблема |
| Развитие | | нарастание, повороты, сколько «петель интереса» |
| Кульминация | | пик, развязка, «вау»-момент |
| Призыв к действию (CTA) | | что просят сделать и как (голос, текст, жест) |

Отметить: общая длительность, доля каждого блока в %, есть ли зацикливание (конец переходит в начало — важно для Shorts/TikTok).

## Шаг 3. Голос и музыка

- Темп речи: слов в минуту (слова / минуты речи), где ускоряется и замедляется.
- Паузы: где и какой длины, для чего (драматизм, шутка, переход).
- Голос: мужской/женский/детский/персонаж, интонация, энергия, эмоция.
- Музыка: настроение (весёлая, тревожная, эпичная, милая…), примерный темп (BPM), жанр, где меняется, совпадают ли склейки с битом.
- Звуковые эффекты: whoosh, pop, удары, смех и т. п., где стоят.

## Шаг 4. Визуальные приёмы

- Частота смены кадров: число склеек / длительность, средняя длина кадра в секундах; отдельно для хука.
- Крупность и движение камеры: крупные планы, зум, панорамы, тряска.
- Эффекты и переходы: появление объектов, переходы, свечение, частицы, скорость.
- Текст на экране: субтитры, стиль, крупные слова, эмодзи.
- Цвет и стиль: палитра, стиль рисовки, формат кадра (9:16, 16:9).

## Шаг 5. Разбор → файл

Сохранить разбор в `stsenarii/<NN>-<slug>.analiz.md`: ссылка на источник, дата, итоги шагов 1–4 и короткий список «Что берём в наш мультик» (5–7 приёмов).

## Шаг 6. Сценарий нашего мультика

Писать **оригинальный** сценарий: переносить приёмы (тип хука, ритм, структуру, длину кадров, настроение), а не копировать сюжет, персонажей, реплики, графику или музыку источника.

Сохранить в `stsenarii/<NN>-<nazvanie>.md` (номер — следующий свободный в папке, название латиницей, через дефис). Тот же `<NN>-<nazvanie>` потом используется для `golos/` и `gotovo/`.

Формат файла:

```markdown
# <Название мультика>

- Формат: 9:16, 1080×1920 (или 16:9)
- Длительность: ~NN с
- Источник приёмов: stsenarii/<NN>-<slug>.analiz.md
- Голос: <кто, интонация, темп ~NNN слов/мин>
- Музыка: <настроение, темп; брать только трек из muzyka/ с правом на использование>

## Таймлайн

| # | Время | Кадр (что на экране) | Текст озвучки | Звук / музыка / эффект |
|---|---|---|---|---|
| 1 | 0:00–0:01 | ... | ... | ... |
| 2 | 0:01–0:03 | ... | ... | ... |

## Текст озвучки целиком

<все реплики подряд — для записи в golos/>
```

Правила таймлайна:
- Строки 1–2 — хук, укладывается в первые 3 секунды.
- Длительность кадров — как у источника (±20 %).
- Объём текста в каждой строке должен успевать прозвучать за время строки при выбранном темпе.
- Последняя строка — CTA.
- Каждая строка «Кадр» должна быть достаточно конкретной, чтобы по ней собрать сцену в Remotion или HyperFrames.

## Итог для пользователя

Коротко: главное о хуке, структуре, голосе/музыке и визуале источника, путь к разбору и к сценарию.
