# ai-art-prompter — единый стиль персонажей и фонов

## Пути проекта

- `stsenarii/<id>.md` — сценарий: из колонки «Кадр» берутся сцены.
- `render/stil/stil.md` — **библия стиля** (одна на весь канал или серию).
- `render/stil/personazhi/<imya>.md` — карточка персонажа; `render/stil/personazhi/<imya>/` — референсы.
- `render/stil/prompty/<id>.md` — промпты на кадры ролика.
- `render/assets/<id>/` — сгенерированные оригиналы (`kadr-01-fon.png`, `kadr-01-geroi.png`…); общие для всех роликов — `render/assets/obshchie/`.
- Дальше: навык `asset-compressor` сжимает их в `render/remotion/public/<id>/kadry/`.

`<id>` — имя ролика вида `01-nazvanie`, как у сценария.

## Порядок

1. **Библия стиля.** Если `render/stil/stil.md` нет — создай по шаблону `shablony/stil.md`: спроси у пользователя (или возьми из разбора video-analyst, агент 8 «Стилист») стиль, палитру, свет, формат. Один раз зафиксированный «Блок стиля» дальше копируется в промпты **слово в слово**.
2. **Карточки персонажей.** Для каждого героя из сценария, у которого нет карточки, — `shablony/personazh.md`. «ДНК персонажа» — короткая фиксированная фраза с отличительными признаками (силуэт, цвета, одежда, 1–2 уникальные детали) в постоянном порядке. Первым делом генерируется **лист персонажа** (вид спереди, сбоку, сзади, 3–4 эмоции на нейтральном фоне) — потом он служит референсом.
3. **Промпты на кадры.** Для каждой строки таймлайна сценария — запись в `render/stil/prompty/<id>.md` по `shablony/prompty.md`. Персонажей и фоны генерируй **раздельно** (персонаж на однотонном фоне для вырезки, фон без персонажей), чтобы в Remotion/HyperFrames их можно было анимировать слоями. Повторяющиеся фоны генерируй один раз и переиспользуй.
4. **Генерация.** Если у пользователя есть доступ к генератору через API/инструмент — генерируй и сохраняй в `render/assets/<id>/`. Если нет — отдай промпты пользователю и скажи, куда положить файлы.
5. **Проверка стиля.** Посмотри каждую картинку (Read) рядом с листом персонажа и сверь по чек-листу ниже. Не прошла — поправь промпт (усиль «ДНК», добавь в негатив то, что уплыло) и перегенерируй, а правку запиши в `stil.md` → «Журнал правок».

## Правила стабильного промпта

Порядок частей всегда один:

```
[Блок стиля — дословно из stil.md], [ДНК персонажа — дословно из карточки], [поза и действие], [эмоция], [план и ракурс], [окружение/фон], [свет — из stil.md], [формат]
```

- Никаких синонимов: если в библии «тёплый закатный свет», не пиши «оранжевое освещение».
- Одна сцена — одно действие; сложные сцены дели на слои.
- Цвета — названиями из палитры библии (и HEX в карточке для проверки).
- Негативный промпт (где поддерживается) — общий из библии + свой для кадра.
- Формат: 9:16 для Shorts/TikTok, 16:9 для YouTube — из библии.
- Записывай **seed** удачных картинок и используй его для вариаций того же кадра.

Механизмы привязки к референсу по генераторам (проверь актуальные параметры в документации генератора — они меняются):
- **Midjourney:** `--sref <ссылка на картинку стиля>` + `--sw`, персонаж — omni-reference `--oref` (v7) или `--cref` (v6), `--seed`, `--ar 9:16`, `--no …`.
- **Flux / SDXL / Stable Diffusion:** фиксированный seed, LoRA персонажа (если обучена), IP-Adapter / reference по листу персонажа, отдельный negative prompt.
- **GPT Image / DALL·E и редакторы по картинке:** seed нет — прикладывай лист персонажа как входное изображение и проси «тот же персонаж, тот же стиль», меняя только позу и сцену.
- **Ideogram, Leonardo и др.:** style reference / character reference, если есть; иначе — тот же порядок промпта и seed.

## Чек-лист стиля для каждой картинки

- [ ] силуэт и пропорции как на листе персонажа;
- [ ] цвета персонажа и одежды из карточки, без новых деталей;
- [ ] толщина линий, текстура, детализация как в библии;
- [ ] палитра фона из библии, свет с той же стороны и той же температуры;
- [ ] формат и запас по краям под анимацию (зум, панораму);
- [ ] нет текста, логотипов, водяных знаков, лишних пальцев/конечностей.

## Авторские права

Не используй в промптах имена живых художников, названия студий и чужих персонажей, чтобы скопировать их стиль или героя. Описывай стиль признаками (линии, цвета, свет, фактура).
