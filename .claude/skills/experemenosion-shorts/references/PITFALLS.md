# Все ошибки, которые пользователь поправлял, и как их не повторить

Читать перед сборкой и перед сдачей. Каждая строка — реальная правка из работы над стилем и роликом «Бешенство».

## Звук
1. **Голос и звуковые эффекты не нужны.** Пользователь: «Убери озвучку, оставь только музыку». В ролике только музыкальный трек. Никакого TTS-хука, свушей, щелчков, писка монитора, рычания. (Системный голос Windows к тому же звучал роботизированно.)
2. **Музыка «без души», «звынь-звынь»**: колокольчик весь ролик повторял одно арпеджио восьмыми по 4 аккордам, мелодии не было. → Только `tools/music2.mjs`: главная тема на 8 тактов (фраза, ответ, подъём, развязка), ведущий голос с легато и вибрато, живое пианино (сила удара, микросдвиги), струнные, хор, виолончель, драматургия по секциям. Никаких сплошных арпеджио-«шкатулок».
3. Пики доходили до 0 dB → финализация `loudnorm I=-14 + alimiter 0.84`, пики ≤ −1 dB.
4. Низ спектра был перегружен (200–500 Гц, «глухо») → ФВЧ 140 Гц на всех шинах кроме баса/ударных, струнные на октаву выше, без дублей баса пианино в ритмических частях.
5. Я не могу слушать звук. Музыку проверять по цифрам и спектрограмме и честно писать «на слух не проверено».

## Титры
6. **Красный акцент — горизонтальный глитч-смаз**, а не «шершавые» края (первая версия была с мелкой шероховатостью). Фильтр `#rough` в `Caption.tsx` уже правильный, не менять.
7. **Красное на красном не читается** (сцена с кровью/сосудом) → на красных сценах акцент делать жёлтым `{..}`.
8. Шрифт — только Unbounded 900 (проверено против Russo One, Dela Gothic, Rubik Mono, Montserrat — те не похожи).

## Персонажи и рисунок
9. **Лицо «дефолтным кругом/овалом»** — главная претензия к первому лицу. Форма головы строится по точкам (лоб, виски, скулы, брыли, подбородок), плюс ~10 слоёв аэрографа, две фактуры кожи, двойные морщины с разрывами. Использовать `FaceOld`, новых героев делать тем же методом.
10. Слишком насыщенная «чистая» кожа и мультяшные глаза → приглушённая палитра, небольшие глаза с тяжёлым веком, блюр 0,6 px.
11. Мешки под глазами вышли как синяки → лиловая тень с прозрачностью ≤ 0,42.
12. Голова мелкая, шея длинная → голова ≈ 55 % ширины, плечи подняты (шея короткая), падающая тень от челюсти на шею, на шее только кольца-морщины.
13. При «стирании лица» уплывал контур головы → размазываются только черты внутри овала, контур целый, поверх — горизонтальные мазки тонов кожи.
14. **В хуке не было рук** — стакан висел в воздухе → `HandsWithGlass`: обе руки обхватывают стакан, дрожат.
15. **Рука без проработки и текстур** → `OldHand`: суставы, ногти с лункой, вены, сухожилия, пятна, волоски, вязаный рукав, укус с рваными проколами и кровью.
16. Сцена в постели: лицо повернули на 90° и из-под одеяла торчало туловище → при виде сверху лицо не поворачивать, одеяло рисовать поверх тела.

## 3D и вставки
17. **Плоская 2D-лиса без лап** («просто 2D-лиса») → полноценная 3D-лиса из `src/fox3d/` с настоящими ногами, рысью, подкрадыванием, прыжком и укусом. Любое животное/героя-в-движении делать в 3D тем же SDF-методом.
18. **«Она не боялась людей» — только морда** → показывать действие: вид сбоку, нападение, укус, падение. Если титр про действие — в кадре действие.
19. **Огород «плохо проработан»** → 3D-сцена с грядками, растениями, забором, домом с тёплым окном, луной, туманом, звёздами.
20. **«Рентген» был силуэтом с линией** («должен быть как реальный рентген») → `XrayShot`: настоящая 3D-анатомия с плотностью вдоль луча, кортикальный слой, рёбра, лёгкие, маркер «R», линейка, светящийся путь возбудителя.
21. **Одни и те же кадры по всему ролику** («скучно смотреть») → у каждого такта свой план (см. STYLE_GUIDE §2.5): не более 2 одинаковых подряд, портрет ≤ 6 раз и всегда в новом варианте.
22. 3D-нерв пересвечен, вирусы повёрнуты к камере плоским донцем (выглядели дисками) → умеренный свет; вирусы ориентировать боком (наклон 45/90 к направлению), чтобы читался профиль «пули».
23. Бумажное сердце узкое «как клубника» → шире, с предсердиями, двойная штриховка, рамка-таблица.
24. 3D-дед крупно днём выглядит маской → 3D-людей держать дальше/ночью/сбоку, крупные планы людей — только 2D.
25. Карточки на чёрном фоне выглядят пусто → под карточкой размытая сцена из этого ролика (blur 14, яркость 0,75).

## Факты
26. Цифра ВОЗ устарела (было 59 000, на сайте ВОЗ уже 44 203 по оценке 2021) → каждую цифру проверять на первоисточнике в день работы и указывать год оценки.
27. Неточное «спорное» число (выжившие) → писать «единицы», а не придуманное точное.

## Технические ловушки
28. SMIL `<animateMotion>` не управляется кадром Remotion → позицию по пути считать самому (выборка Безье).
29. Instanced-матрицы в эффектах/рефах → первый кадр каждой вкладки рендера пустой. Обновлять матрицы синхронно в рендере, InstancedMesh создавать в useMemo и вставлять через `<primitive>`.
30. Отрицательное время в Three-сцене (нырок показывает сцену раньше её такта) → `getPointAt(<0)` падает с `Cannot read properties of undefined (reading 'x')`. Все параметры пути клампить в [0.001, 0.99].
31. Рендер в путь с кириллицей тихо не создаёт файл → рендерить в `out/` (латиница), потом копировать.
32. `npm install` не запускает postinstall esbuild → `npm approve-scripts esbuild && npm rebuild esbuild`.
33. Файлы > 30 МБ не доходят до телефона → всегда делать копию 720p (`*_превью.mp4`).
34. Логи рендера обрезаются хвостом → писать лог в файл и искать `An error occurred while rendering frame N`.
35. Всё детерминировано: только `mulberry` из `rand.ts`, никаких Math.random/Date/useFrame.
