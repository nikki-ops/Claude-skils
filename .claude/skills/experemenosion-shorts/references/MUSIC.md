# Музыка: генератор `tools/music2.mjs` и правила

В ролике только музыка, своя, написанная кодом. Ни сэмплов, ни чужих треков, ни голоса, ни звуковых эффектов.

```bash
node tools/music2.mjs src/<slug>/music_plan.json public/<slug>_music.wav
```
Около 75 с на 36 тактов. Результат детерминирован: тот же план даёт тот же файл.

## Что внутри генератора
- **Пианино**: 3 струны на ноту с расстройкой, 10 обертонов с негармоничностью, яркость зависит от силы удара, удар молоточка, у каждой ноты своя громкость и сдвиг по времени ±8 мс.
- **Струнные**: 7 расстроенных пил, ФНЧ, медленная атака, вибрато с задержкой, тремоло (`trem`).
- **Хор «а-а»**: пила через 3 форманты (760/1150/2650 Гц), вибрато.
- **Ведущий голос темы**: треугольник + немного пилы, легато (портаменто), вибрато, дыхание.
- **Виолончель** в басе, саб-808 в ритмических секциях.
- **Ударные**: живые бочка, малый барабан и хэты, ритм half-time, микросдвиги, триольные роллы в тревоге.
- **Эффекты музыки**: удар-«бум» на старте секций, райзер перед тревогой и финалом.
- **Сведение**: реверб с предзадержкой, сайдчейн от бочки на струнных и хоре, ФВЧ 140 Гц на всём кроме баса и ударных, мягкая компрессия шины и нормализация пика 0,89.

## План трека (`music_plan.json`)
```json
{ "bpm": 96, "bars": 36,
  "sections": [ {"from":0,"chords":["Am"],"sec":"hook"}, {"from":1,"chords":["Am","F","C","G","E"],"sec":"intro"},
    {"from":6,"chords":["Am","F","C","G","Am","F","Dm","E"],"sec":"dropA"},
    {"from":14,"chords":["Dm","Am","E","Am","Dm","Am","E7","E","F","Dm","E"],"sec":"tension"},
    {"from":25,"chords":["F","Fmaj7"],"sec":"break"}, {"from":27,"chords":["C","G","Am"],"sec":"lift"},
    {"from":30,"chords":["Am","F","C","G","E"],"sec":"final"}, {"from":35,"chords":["Am"],"sec":"outro"} ],
  "melodies": [ {"bars":[6,7,8,9,10,11,12,13],"theme":"THEME","vel":0.55,"inst":"lead"}, ... ] }
```
- Аккорды из словаря `CH`: `Am F C G Dm E E7 Em Fmaj7`. Новые аккорды добавлять туда же: `[бас, [3 ноты]]`.
- Темы: `THEME` — 8 тактов, основная; `THEME_T` — тревожный вариант на 4 такта: быстрее, выше, с повторяющимися нотами. Свою тему можно передать в `themes: {THEME: [...]}`, формат такта: `[[доля, длительность в долях, "нота"], ...]`.
- `melodies[].phrases` — номера фраз темы (например `[4,5,6,7]` = вторая половина), `oct` ±12, `inst` `lead` или `piano`.

## Секции и что они делают
| sec | роль в сюжете | звучание |
|---|---|---|
| `hook` | хук | удар + низкая октава пианино + струнная нота |
| `intro` | завязка | одинокое пианино (бас + тихие аккорды) ведёт тему, тихий пад; в последнем такте тремоло и райзер |
| `dropA` | первая вставка «внутри», тихая фаза | тема целиком на ведущем голосе, пианино ломаными аккордами, струнные, виолончель, 808, ударные |
| `tension` | эскалация симптомов | тремоло струнных, хор, тревожная тема, роллы хэтов, «бум» сильнее |
| `break` | смерть/потеря | 1-й такт — тихое пианино и фраза темы, 2-й — одна тающая высокая струна и райзер |
| `lift` | «могло быть иначе» | светлый мажорный поворот, ударные мягче, тема на пианино |
| `final` | карточки-цифры | кульминация: тема на ведущем голосе + пианино октавой выше + хор |
| `outro` | петля | одинокое пианино и пад |

## Правила
1. **Темп = монтажная сетка.** `bpm` трека = `bpm` в `shots.json`, такт трека = такт ролика. Секции стоят на тех же тактах, что и блоки сценария: `dropA` = `dropBar`, `break` = `breakBars`, `lift` = `secondDrop`.
2. **У трека есть тема и мелодия.** Никаких сплошных арпеджио «колокольчиком» на весь ролик. Тема звучит хотя бы в `intro` (пианино), `dropA` (голос) и `final` (голос + пианино).
3. **Драматургия по сюжету.** Ориентиры громкости RMS по тактам: интро около −25 dB, дроп около −14, тревога −14…−13, брейк около −29, поворот около −17, финал около −13, аутро около −30.
4. **Тональность** — минор (по умолчанию ля минор). Новая тема должна петь: ходы по ступеням, вершина фразы, развязка на устой.
5. **Пики ≤ −1 dB, низ подрезан.** Финализация (`scripts/finalize.sh`) делает loudnorm −14 LUFS + лимитер. Сам WAV генератора нормализован на 0,89.
6. В композиции один `<Audio src={staticFile("<slug>_music.wav")} volume={0.9} />`.

## Проверка (обязательно, я не слышу звук)
```bash
python scripts/qa_music.py public/<slug>_music.wav --bpm 96 --out checks/
```
Скрипт проверяет и сохраняет:
- темп (±1 BPM от плана);
- RMS по тактам (профиль должен совпадать с драматургией);
- пик (≤ 0,9);
- центроид (≥ 1100 Гц);
- долю 200–500 Гц;
- топ нот (ля минор: A, E, C, G, F);
- спектрограмму `checks/spectrogram.png`. На ней видны линия темы около 700–1100 Гц и удары на стартах секций, без сплошной «каши» и без однообразной сетки арпеджио.

В отчёте пользователю всегда писать: «музыка проверена по цифрам и спектрограмме, на слух не проверена».
