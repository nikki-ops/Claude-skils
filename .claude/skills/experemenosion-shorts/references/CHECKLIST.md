# Чек-лист самопроверки перед сдачей

Отмечать каждый пункт по факту (по кадрам и цифрам, а не по памяти). Если пункт не прошёл — исправить и перепроверить. В отчёте пользователю писать, что проверено и что нет.

## 1. Рендер и файл
- [ ] `ffprobe`: 1080×1920, 30 fps, длительность = bars × 2,5 с (90 с), есть аудиодорожка.
- [ ] В логе рендера нет `An error occurred`; файл не нулевой.
- [ ] Финальный mp4 и копия 720p `*_превью.mp4` (< 30 МБ) лежат в папке ролика.

## 2. Картинка (`python scripts/qa_video.py <mp4> --bpm 96 --out checks/`)
Смотреть лист `checks/bars.jpg` (кадр 50 каждого такта) и `checks/cuts.txt`.
- [ ] Каждый такт — свой план; подряд ≤ 2 одинаковых типа; портрет ≤ 6 раз и каждый раз в другом варианте.
- [ ] Хук: конечное состояние героя, руки в кадре, HUD почти пуст. Последний такт = кадр хука (петля).
- [ ] Лица: форма по точкам, аэрограф, фактура — не «круг». 3D-люди не крупно.
- [ ] Действие из титра показано действием (нападение, укус, судорога), а не статичной мордой.
- [ ] Вставки: процесс в кадре + сноска-цифра меняется; рентген выглядит как снимок.
- [ ] Ничего не выжжено светом, нет пустых/чёрных кадров (кроме задуманного), нет торчащих частей (туловище из-под одеяла и т. п.).
- [ ] Верх кадра (y < 420) спокойный, HUD и титры читаются; низ под сноску свободен.
- [ ] Карточки на размытой сцене, а не на чёрном.

## 3. Титры
- [ ] Unbounded 900, прописные, ≤ 2 строк, ≤ 22 символа в строке, не вылезают за 900 px.
- [ ] Красные акценты с горизонтальным глитчем; на красных сценах акцент жёлтый.
- [ ] Анимация: слова влетают по одному (шаг 3 кадра), уходят разлётом в последние 5 кадров.
- [ ] Факты совпадают со сценарием и источниками.

## 4. Синхрон с долями
- [ ] `checks/cuts.txt`: все жёсткие склейки на кратных такту (75 кадров при 96 BPM) ± 1 кадр (кроме задуманных внутрикадровых переходов: нырок, вспышка).
- [ ] Титр стартует на +2 кадра после склейки.
- [ ] Удары музыки (`boom`) на старте `dropA`, `tension`, `lift`, `final` совпадают со склейками.
- [ ] Тряска и красная пульсация совпадают с влётом красного слова.

## 5. Музыка (`python scripts/qa_music.py <wav> --bpm 96 --out checks/`)
- [ ] Темп = BPM сетки ± 1.
- [ ] RMS по тактам повторяет драматургию: тихое интро → дроп → тревога → провал на брейке → поворот → кульминация → тихий финал.
- [ ] Пик WAV ≤ 0,9; в финальном mp4 `max_volume` ≤ −1 dB, `mean_volume` около −15 dB.
- [ ] Центроид ≥ 1100 Гц, доля 200–500 Гц не доминирует (низ подрезан).
- [ ] Топ нот соответствует тональности.
- [ ] Спектрограмма: видна гуляющая линия темы, нет однообразной сетки арпеджио по всему треку.
- [ ] В ролике нет голоса и звуковых эффектов, только музыка.

## 6. Отчёт пользователю
Ссылка на mp4 1080×1920 и превью 720p (отправить превью файлом), лист кадров, короткий список «что сделано», «что слабее всего», «музыка проверена по цифрам, на слух не проверена».
