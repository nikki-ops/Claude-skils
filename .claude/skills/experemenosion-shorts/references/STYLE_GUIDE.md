# Стиль-гайд в числах

Стиль снят с роликов @experemenosion (4 ролика по 90 с: танцевальная чума, голод, спорынья, Альцгеймер) и отработан на ролике «Бешенство», который пользователь принял после трёх итераций. Оригиналы открывать не нужно, всё нужное здесь.

Формат: 1080×1920, 30 fps, ровно 90 с. Язык — русский. Голоса и звуковых эффектов нет, только музыка (см. PITFALLS).

---

## 0. Главное правило монтажа: всё на сильную долю

Ролик режется по тактам трека. Каждая склейка и каждая смена титра стоит ровно на сильную долю.

| темп | такт | шаг склеек | титр живёт |
|---|---|---|---|
| 80 BPM | 3,0 с | 3,0 с | 1 такт |
| **96 BPM (по умолчанию)** | **2,5 с = 75 кадров** | **2,5 с** | **1 такт** |
| 128 BPM | 1,875 с | 3,75 с | 2 такта |
| 150 BPM | 1,6 с | 1,6 / 3,2 с | 1–2 такта |

Правило: при ≤ 100 BPM один план и один титр на такт, при > 120 BPM — два такта. По умолчанию 96 BPM × 36 тактов = 90 с. Титр стартует на кадре +2 после склейки. В коде: `grid(bpm).at(bar, beat)` из `src/style/tokens.ts`; в `shots.json` один элемент = один такт.

## 1. Сценарий по секундам (96 BPM, 36 тактов)

| время | такты | блок | что в кадре | музыка |
|---|---|---|---|---|
| 0:00–0:02 | 0 | **ХУК** | Флэш-форвард: самое страшное состояние героя из конца истории (дед в ужасе со стаканом, руки дрожат). HUD уже на конечных значениях («ДЕНЬ 47 · ШАНС 0 %»). Титр-приговор в 2 строки, вторая красная | удар + низкое пианино |
| 0:02–0:15 | 1–5 | **Завязка** | Герой (имя, возраст, место, месяц), как всё началось (заражение, событие). Последний такт — наезд/нырок к дропу | тихое пианино с темой |
| 0:15 | 6 | **Дроп = первая вставка «внутри»** | Механизм: вирус/клетки/орган крупно, переход нырком | вступают ударные, тема целиком |
| 0:15–0:35 | 6–13 | **Тихая фаза** | Чередование: вставка → герой («прошёл месяц, всё хорошо») → вставка (возбудитель движется) | дроп |
| 0:35–1:02 | 14–24 | **Эскалация** | Удар (возбудитель достиг цели) → симптомы на герое, каждый такт новый симптом и новый ракурс; вставки органов между ними | тревога: тема выше, тремоло струнных, хор |
| 1:02–1:07 | 25–26 | **Кульминация** | Смерть/потеря: герой сереет, монитор в линию | брейк: почти тишина |
| 1:07–1:15 | 27–29 | **Поворот** | «А могло быть иначе»: HUD отматывается к ДНЮ 0 и 100 %, что спасает (простое действие, лечение) | светлый поворот |
| 1:15–1:27 | 30–34 | **Итоговые карточки** | 4–5 огромных цифр по одной на такт, на размытых кадрах ролика, сноска-источник | кульминация темы |
| 1:27–1:30 | 35 | **Петля** | Тот же кадр, что в хуке, новый титр («ВЫЖИВШИХ — ЕДИНИЦЫ») | тихое пианино → в начало |

### Подача фактов
- Один факт = один титр = один такт. 2–6 слов, 1–2 строки, ≤ 22 символа в строке.
- Строка 1 (белая) — контекст, строка 2 (акцент) — удар: «ГОРЛО СВОДИТ / [СУДОРОГОЙ]».
- Цифры вшиты в картинку: HUD сверху, сноска под объектом (y≈1680–1700), счётчики меняются на долях.
- Один герой с именем, возрастом, местом. Повествование в третьем лице, коротко, рублено.
- Термины переводятся на бытовой язык: «гидрофобия → один вид воды вызывает спазм».
- Всего 30–36 титров, 110–150 слов на экране, 1,3–1,7 слова/с.
- Все факты и цифры проверяются по первоисточнику (ВОЗ и т. п.) в день работы; художественные шкалы (ШАНС, ДО МОЗГА) помечаются в сценарии как художественные.

### Хук
1. Кадр из конца истории. 2. Титр-приговор с красным акцентом. 3. HUD уже почти пустой. 4. Дрожь/движение в кадре (руки, стакан, дыхание). Голоса нет.

### Финал
4–5 карточек-цифр («44 000 / СМЕРТЕЙ В ГОД / оценка ВОЗ, 2021»), затем петля на кадр хука с фразой-уколом.

## 2. Визуальный стиль

### 2.1 Общий каркас
- **Зерно**: монохромный шум 12 смен/с, overlay, ~10 % (`<Grain amount={0.1} vignette={0.6}/>`).
- **Виньетка**: радиальная 0,55–0,75 от 45 % радиуса.
- **Камера**: внутри каждого плана движение не прекращается: наезд 5–7 % за такт, «дыхание» ±0,4 %, в 3D — долли/облёт. Статики дольше 1 с нет.
- **Верхние 22 % кадра** (y < 420) спокойные/тёмные — там HUD и титры. Низ y≈1680–1720 свободен под сноску.

### 2.2 Портрет героя (2D, аэрограф) — `FaceOld`
- Фронтально, по центру, голова ≈ 55 % ширины кадра (в FaceOld это viewBox "70 190 940 1671").
- **Форма головы — не овал.** Строится по точкам: широкий плоский лоб → впадина виска → скула → брыли → широкий подбородок; ширина ≈ 0,7 высоты.
- **Светотень аэрографом**, ~10 размытых слоёв поверх заливки: свет на лбу/лысине, тени висков, свет на скулах и тень под ними, румянец, лиловые глазницы, брыли, тень подбородка, падающая тень на шею.
- **Фактура кожи**: крупная пятнистость (feTurbulence 0.012) + мелкий шум (0.55) умножением; пигментные пятна 4–12 px; щетина мелкими точками 16 %.
- **Морщины** — двойной штрих (широкий полупрозрачный + узкий плотный) с разрывами: лоб (короткие, прерывистые), межбровье, «гусиные лапки», мешки (2 дуги), носогубные, над губой, подбородок, шея (кольца, без вертикальных линий).
- Брови — ~90 коротких штрихов; нос без контура спинки (две линии + кончик + ноздри); глаза миндалем с нависающим веком, радужка с ободком и бликом.
- Контур 3 px #6B3D2E только по силуэту головы. Общий блюр 0,6 px. Кожа приглушена: #E2B59C / #C99179 / #94604E.
- **Фон портрета**: тёплый почти чёрный #140D08 + янтарное пятно света сбоку-сзади (`WarmPortraitBG`).
- Состояния (props FaceOld): `fear, pupil, redEye, sweat, flush, spasm, drool, pallor, erase, blink, mouth, look`.
- **Деградация**: бледность (насыщенность −85 %), «стирание» (черты размазываются горизонтальными мазками тонов кожи, контур головы остаётся целым).

### 2.3 3D-сцены (Three.js, процедурно)
- Животные и люди в 3D строятся SDF-моделированием (сглаженные объединения эллипсоидов/капсул) + свой мешер, скелет с IK, мех оболочками (16–26 слоёв). Примеры: `src/fox3d/` (лиса с рысью/подкрадыванием/прыжком/укусом, дед, огород ночью и днём).
- Свет ночью: холодная луна (ключ+контур), тёплое окно точечным светом, туман, звёзды. Днём: тёплое низкое солнце.
- **3D-люди держать дальше/сбоку/силуэтом**: крупно их лицо выглядит маской. Крупные планы людей — только 2D-портрет FaceOld.

### 2.4 Вставки «внутри тела»
Что показывают: путь возбудителя, орган крупно, клетки, разрез, рентген, микроскоп.
Почему выглядят реально:
1. Свечение (аддитивные спрайты) и горячие ядра.
2. Тёмный фон + туман глубины.
3. **Процесс в кадре**: растёт/гаснет/сжимается прямо сейчас, сноска-цифра меняется синхронно.
4. Медицинская палитра: нейроны #22A9DC, бляшки #FF9424, вирус #9BFF4A, кровь #C8161C, артерии красные, вены синие, нерв янтарный.
5. Сноска-термин под объектом (Montserrat 800, 34–44 px).

Каталог готовых вставок — `SCENES.md` (3D-рентген, 3D-нерв, 3D-сосуд, 3D-нейроны, разрез головы, микроскоп, срез нерва, бумажная анатомия, глаз крупно).

### 2.5 Монтаж
- ~90 % жёсткие склейки на долю, план = 1 такт.
- Особые переходы: вспышка 3 кадра белым на дропе и втором дропе; **нырок** (наезд в точку ×7 с кубическим ease + раскрытие круга со следующей сценой в последней трети такта); на карточках цифра «пролетает» в камеру.
- **Тряска** 9 кадров (затухание exp(−0,45d), амплитуда 14 px) и **красная пульсация виньетки** в момент влёта красного слова и на ударе в сюжете (укус).
- **Разнообразие**: у каждого из 36 тактов свой план. Подряд не более 2 планов одного типа; фронтальный портрет — не более 6 раз за ролик и каждый раз в другом варианте (руки/стакан, крупно, рот, ветер, постель).

## 3. Титры

| параметр | значение |
|---|---|
| шрифт | **Unbounded 900** (Google Fonts, `FONT_TITLE`) |
| регистр | только ПРОПИСНЫЕ |
| размер | база 90 px (74 px если текст > 26 символов), строка подгоняется до ≤ 900 px, строка-акцент ×1,12 |
| место | по центру, верх блока y = 262, 1–2 строки, межстрочный 1,1, трекинг −2,5 % |
| белая строка | #F2F2F0, чёрная обводка ≈ 5 % кегля (8 теней), тень вниз 1,3× обводки |
| красный акцент `[..]` | #F42A10, тёмно-красная подошва #5A0700, свечение rgba(244,42,16,.6) радиусом 35 % кегля, **горизонтальный глитч-смаз** (feTurbulence 0.003×0.22 → displacement по X 22 px) |
| жёлтый акцент `{..}` | #FFD000, чёрная обводка, свечение rgba(255,208,0,.55) радиусом 30 % |
| градиент | внутри букв нет; «объём» — свечение + подошва |
| появление | по словам: 5 кадров, масштаб 1,55→1, блюр 9→0, прозрачность 0,35→1, из серого в цвет, out-cubic; шаг 3 кадра; строка-акцент +2 кадра |
| уход | последние 5 кадров такта: слова разъезжаются (0,6 em × номер от центра), блюр 7, масштаб 1,06, исчезают |
| привязка | к музыке: старт на долю +2 кадра, живёт ровно такт |

Разметка в `shots.json`: `"ОН ХОЧЕТ ПИТЬ\n[НО НЕ МОЖЕТ]"`, `"ЗАШЛА {ЛИСА}"`.

### HUD
- Пилюли сверху: y = 174, высота 62, фон rgba(6,8,8,.82).
- Слева «● ДЕНЬ 11» — Montserrat 800, 34 px, точка 16 px #FF2B1C со свечением.
- Справа: подпись 25 px («ШАНС», «СИЛЫ», «ПАМЯТЬ»), шкала 208×17, процент 31 px; цвет шкалы > 60 % #2FE07A, > 25 % #FF970F, иначе #F42A10. Значение плавно меняется за такт `[label, from, to]`.
- Нижний счётчик (`Counter`) y≈1410–1440, 52 px, жёлтый; в критической зоне красный.
- На карточках HUD нет.

### Итоговые карточки (`StatCard`)
Число Unbounded 900 до 190 px (жёлтое или красное, свечение 25 %), y = 760; ниже белая строка 40 px; ниже сноска 24 px #9A9A9A. Влёт 7 кадров back-ease, уход: число ×3,2 с блюром. Фон — **размытая сцена из этого же ролика** (blur 14, яркость 0,75) + тёмное пятно под текстом + тлеющие искры.
