# Ролики про болезни и способы смерти в стиле @experemenosion

Стиль уже разобран и отработан на ролике «Бешенство», который пользователь принял. Все числа стиля лежат в `references/`, разбирать оригиналы заново не нужно и нельзя: ничего из роликов автора не переносим, только приёмы.

## Жёсткие правила
- Картинка только кодом: Remotion + Three.js (SVG, canvas, шейдеры, процедурная геометрия). Без нейросетей для картинок и видео, без скачанных моделей, текстур и изображений.
- Музыка только своя, кодом (`tools/music2.mjs`). **В ролике только музыка: без голоса и без звуковых эффектов.**
- Из роликов автора не переносим кадры, тексты, музыку — только приёмы.
- **Два шага.** Шаг 1 — сценарий и ожидание «ок». Полный ролик до «ок» не начинать. После «ок» — всё сам, без вопросов.
- Факты и цифры проверять по первоисточнику (ВОЗ и т. п.) в день работы, указывать год оценки.
- Я не слышу звук: музыку проверять по цифрам и спектрограмме и честно писать «на слух не проверено».

## Шаг 1. Сценарий (до «ок»)
1. Прочитать `STYLE_GUIDE.md`, `SCRIPT.md`, `PITFALLS.md`.
2. Найти и проверить факты по теме (WebFetch/WebSearch на сайт ВОЗ, CDC, обзоры): механизм, сроки, симптомы, что спасает, 4–5 цифр для карточек с годом.
3. Придумать героя (имя, возраст, место, время года), источник/событие, путь болезни в теле, симптомы — каждый такт свой план и свой ракурс.
4. Разложить на 36 тактов по шаблону `SCRIPT.md`, подобрать `kind` из `SCENES.md`, отметить, какие сцены нужно сделать новыми.
5. Сохранить `D:\Болезни Стиль\ролик-NN-<тема>\СЦЕНАРИЙ.md` (или рядом с проектом пользователя) и показать таблицу: `# | время | план | титр | HUD/сноска` + герой, HUD, музыка по секциям, источники.
6. Закончить строкой: «Жду „ок“ — после него соберу ролик целиком». Остановиться.

## Шаг 2. Сборка (после «ок», без вопросов)
1. **Проект.** Если рабочего проекта нет — скопировать `assets/template` в `D:\Болезни Стиль\studio` (или `<папка ролика>/studio`), затем:
   ```bash
   npm ci && npm approve-scripts esbuild && npm rebuild esbuild
   ```
   Если проект уже есть (например, `D:\Болезни Стиль\studio`), работать в нём.
2. **Заготовка:**
   ```bash
   python -I <skill>/scripts/new_video.py <проект> <slug> <Comp>
   ```
   Команда копирует `src/rabies` в `src/<slug>` и регистрирует композицию.
3. **Сценарий в данные.** Заполнить `src/<slug>/shots.json`: 36 элементов, `kind`, `cap` с разметкой `[..]` (красный) и `{..}` (жёлтый), `hud`, `note`. Поля `dropBar`, `breakBars`, `secondDrop` задать по сценарию.
4. **Сцены.**
   - Готовые сцены брать из `SCENES.md`.
   - Недостающие делать методом соседних компонентов (2D-аэрограф по точкам или 3D SDF) в `src/<slug>/` и добавлять их `kind` в диспетчер `<Comp>Video.tsx`.
   - Удалить ненужные `kind` образца.
   - Каждую новую сцену проверить стоп-кадрами через `previewEntry.tsx`, посмотреть PNG и править до хорошего качества.
5. **Музыка.**
   - Записать в `src/<slug>/music_plan.json` секции на тех же тактах, что в сценарии; тему можно оставить или написать свою.
   - Сгенерировать трек:
     ```bash
     node tools/music2.mjs src/<slug>/music_plan.json public/<slug>_music.wav
     ```
   - Проверить его:
     ```bash
     python -I <skill>/scripts/qa_music.py public/<slug>_music.wav --bpm 96 --out checks/
     ```
6. **Черновая проверка.**
   - Стоп-кадры: кадр 50 каждого такта, `--scale=0.4`, затем лист кадров.
   - Исправить всё по `CHECKLIST.md` §2–3 до полного рендера.
7. **Рендер.** Только в путь латиницей, лог в файл:
   ```bash
   npx remotion render src/index.ts <Comp> out/<slug>.mp4 --gl=angle --crf=18 > out/render.log 2>&1
   ```
   При ошибке найти `An error occurred while rendering frame N`, исправить, повторить.
8. **Финал:**
   ```bash
   bash <skill>/scripts/finalize.sh out/<slug>.mp4 "<папка ролика>" <имя>
   ```
   Получится mp4 1080×1920 (−14 LUFS, пики ≤ −1 dB) и копия 720p `<имя>_превью.mp4`.
9. **Самопроверка:**
   ```bash
   python -I <skill>/scripts/qa_video.py "<папка>/<имя>.mp4" --bpm 96 --out checks/
   ```
   Пройти весь `CHECKLIST.md`, посмотреть `checks/bars.jpg`. Что не прошло — исправить и перерендерить.
10. **Сдача.**
    - Отправить превью 720p файлом.
    - Дать ссылки на полный mp4, `СЦЕНАРИЙ.md` и лист кадров.
    - Коротко написать: что в ролике, что слабее всего, «музыка проверена по цифрам, на слух не проверена».

Подсказка по скорости: 3D-сцены (лиса, рентген) строятся 5–35 с при старте вкладки и рендерятся по 0,3–1,5 с на кадр. Полный рендер 90 с занимает 10–25 минут, его запускать в фоне.

## Как вызвать
Пользователь пишет тему: «сделай ролик про столбняк в нашем стиле», «ещё ролик как бешенство, про угарный газ», «ролик в стиле experemenosion про кессонную болезнь». Скилл отвечает сценарием и ждёт «ок».
